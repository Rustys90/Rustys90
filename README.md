### <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28" alt="wave"/> About

<img align="right" width="380" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="coding" />

**Ankush Chauhan** — full-stack engineer and open-source builder. I don't do tutorials or toy projects: I ship complete, working products — web apps, Android apps, desktop tools, AI pipelines, and the infrastructure around them — then open-source the good ones.

My thing is taking expensive, closed, subscription-locked software and building the **free, open-source, private** alternative: Notion → [Folio](https://github.com/Rustys90/folio), Wispr Flow → [VoxType](https://github.com/Rustys90/voxtype), paid fake-GPS apps → [GhostPin](https://github.com/Rustys90/ghostpin). Clean-room implementations, MIT licensed, no ads, no accounts, no tracking.

Currently: building in public, shipping fast, documenting everything.
