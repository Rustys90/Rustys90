### 👨‍💻 About Me

I'm a solo founder building AI-powered SaaS products, mostly through **AI-assisted development** — working closely with agent-based coding systems to turn ideas into shipped, real products fast.

My focus is on products with real economics: pricing models, unit economics, compliance, and launch blockers worked out end-to-end — not just prototypes.

My long-term goal is simple but ambitious:
**Become an extremely high-level builder and founder.**

### 🚀 What I'm Building

<table>
<tr>
<td width="50%" valign="top">

**🎬 ClipForge**
AI-powered YouTube-to-short-clips SaaS with credit-based billing.

- Production stack: Whisper + Gemini 2.5 Flash-Lite
- Pipeline audited for reliability — race conditions, transcoding stability, and error handling hardened
- CSAM detection via Thorn Safer API built in as a hard launch requirement
- DMCA / DPDP / GDPR compliance addressed in the blueprint
- Tiered pricing (Free → Enterprise) with credit packs, credits that never expire, 90-day clip retention
- Dark UI system: JetBrains Mono for data, Inter for labels, no gradients or glassmorphism — clean, functional, timeline-strip as the signature UI component
- Marketing site: single merged HTML file with hash routing (Home, Pricing, Privacy, Terms, FAQ, Login, Signup, Dashboard)

</td>
<td width="50%" valign="top">

**📈 Stockforge**
AI-driven stock signal and research platform.

- Five-tier pricing model with differentiated stock coverage and refresh intervals
- Core features: Profit Probability Score, Deep Research Reports, Loss Warning System
- Deliberately no raw API access — insight-first, not data-dump
- Full 12-page marketing + app site, merged into a single hash-routed HTML build via a custom Python pipeline
- "Cobalt" design theme
- Handoff PRD includes an honest assessment of architectural fragility and remaining blockers (data licensing, auth, payments)

</td>

**Development workflow:**
- Multi-agent coding system (OpenHands + Claude as a hostile reviewer + LangGraph orchestrator) for building and auditing production code
- Single-file HTML with hash routing as a deployment pattern for shipping fast, merged from multi-page builds via a Python `build.py` + `merge2.py` pipeline
- Playwright headless rendering + pixel measurement used to catch visual bugs before shipping
- New filenames on every deploy to dodge stale browser caching
