### About

Solo builder focused on **agent-native infrastructure** — registries, crawlers, safety gates, and install UX that make agent skills feel like packages.

Currently shipping **[SkillForge](https://skillforge-jet-chi.vercel.app)** — a production registry of public `SKILL.md` skills (Claude, Cursor, Codex, and more), with daily discovery, safety scanning, and one-command install.

```bash
npx skillforge add owner/repo/skill
```
